TapTap - Quick Search

Last updated: October 2026

Overview

TapTap - Quick Search is a browser extension that provides an instant search overlay on any webpage. We are committed to protecting your privacy. This extension does not collect or transmit any personal data. Anything it saves stays on your device.

Data We Do NOT Collect

  • Personal identification information
  • Browsing history or visited URLs
  • Search queries entered in the popup
  • Keystrokes or user activity
  • Location data
  • Any data from the web pages you visit — except the part you choose to save with the Note button, which stays on your device (see below)

Local Storage Only

The extension uses Chrome's storage API to save your preferences locally on your device only. This includes:

  • Selected search engines and their order
  • UI language preference
  • Color theme settings
  • Keyboard shortcut configuration
  • Recent search history (stored locally, never transmitted)
  • New tab preference

This data never leaves your device and is never sent to any server, including ours.

Notes

When you select text on a page and press Note in the popup, the selected part (text, links and images) and the page address are saved in the extension's own database (IndexedDB) on your device only. Nothing is saved unless you press the button.

  • Images in your selection are downloaded directly from the servers that host them, so the note still shows them offline. No other server is involved.
  • Notes are never sent to us or to anyone else, and they are not synced between devices.
  • You can edit or delete any note on the Notes page. Uninstalling the extension deletes all notes.

No Third-Party Data Sharing

We do not sell, trade, or transfer any data to third parties. When you perform a search, your query is sent directly to the search engine you selected (e.g. Google, Naver, ChatGPT) — exactly as it would be if you searched from your browser's address bar. TapTap - Quick Search does not intercept or log these queries.

No Remote Code

This extension does not load or execute any remote code. All functionality is contained within the locally installed extension package. No external scripts, CDNs, or analytics libraries are used.

Permissions

The extension requests the following permissions:

  • storage — Used solely to save your preferences locally. No data is transmitted externally.
  • Host permissions (<all_urls>) — Required to display the search popup overlay on any webpage you visit, and to download the images in a selection you save with the Note button. The extension does not read page content unless you press Note, and never transmits it.

Children's Privacy

This extension does not knowingly collect any information from children under the age of 13.

Changes to This Policy

If we make changes to this privacy policy, we will update the "Last updated" date at the top of this page.
