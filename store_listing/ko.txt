⚡ TapTap - Quick Search — 브라우징 속도를 끌어올리세요

탭 전환은 그만. 주소창 클릭도 그만.
단축키 하나면 어떤 웹페이지에서든 검색창이 바로 뜹니다.
흐름은 끊기지 않고, 답은 그 어느 때보다 빠르게.

단축키 누르고 → 입력하고 → Enter. 끝.


이런 점이 좋아요

TapTap은 매일 나를 느리게 만드는 작은 번거로움을 없애려고 만들었습니다.
자료를 찾을 때도, 글을 읽을 때도, 일할 때도 —
보고 있는 페이지를 떠나지 않고 무엇이든 검색하세요.
이런 순간이 쌓이면 브라우징이 눈에 띄게 빠르고 효율적으로 바뀝니다.


주요 기능

⚡ 바로 뜨는 검색창
단축키 하나로 어떤 웹페이지에서든 검색 팝업을 엽니다.
마우스 클릭도, 탭 전환도 없이 — 입력하고 바로 이동하세요.

🔍 내 방식대로 쓰는 검색 엔진
인기 검색 엔진이 기본으로 들어 있어 바로 쓸 수 있습니다.
무엇보다 좋아하는 검색 엔진을 쉽게 추가하고, 수정하고, 순서를 바꿀 수 있어요.
온전히 나만의 도구로 만드세요.

📝 선택한 텍스트 자동 입력
페이지에서 텍스트를 선택하고 팝업을 띄우면 검색창에 자동으로 채워집니다.
다시 타이핑할 필요 없이 바로 찾아보세요.

🤖 AI 검색 지원
AI 검색 엔진을 기본으로 지원합니다. 검색 URL을 받는 엔진이라면
최신 AI 검색 도구까지 무엇이든 추가할 수 있습니다.

🖱️ 자유로운 엔진 전환
방향키나 마우스 휠로 엔진을 넘겨 보세요.
키보드에서 손을 떼지 않고 원하는 곳에서 찾을 수 있습니다.

🕐 검색 기록
입력하는 동안 최근 검색어가 나타납니다 —
클릭 한 번으로 이전 검색으로 돌아가세요.

🎨 테마 완전 제어
테마 6종, 색상 팔레트 9종, 엔진별 HEX 색상 지정까지.
브라우저의 다크 모드에도 자동으로 맞춰집니다.

⌨️ 단축키 변경
원하는 키 조합을 트리거로 설정하세요.
브라우저 단축키와 겹치지 않도록 충돌을 미리 감지합니다.

🌐 13개 언어 지원
한국어, 영어, 일본어, 중국어(간체), 중국어(번체),
스페인어, 프랑스어, 독일어, 러시아어, 베트남어, 말레이어, 태국어,
인도네시아어.

☁️ 설정이 따라옵니다
한 번만 설정해 두세요. 엔진, 테마, 단축키는 크롬 자체 동기화를 타고
로그인한 모든 컴퓨터에 그대로 나타납니다.

🔒 데이터 수집 없음
제 서버도, 분석도, 추적도 없습니다. 앞으로도. 설정은 브라우저 안에,
크롬 동기화를 켜 두었다면 본인의 구글 계정 안에만 남습니다.


맞춤 설정

팝업의 설정 아이콘을 누르면 설정 페이지가 열립니다:
- 자주 쓰는 검색 엔진 추가, 수정, 순서 변경
- 엔진마다 고유한 색상 테마 지정
- 작업 방식에 맞게 단축키 변경
- UI 언어 변경

팝업 하단에 "새 탭" 스위치가 있어서, 결과를 현재 탭에서 열지
새 탭에서 열지 바로 고를 수 있습니다.


개인정보

이 확장 프로그램은 설정을 저장하기 위한 storage 권한만 사용합니다.
개인 데이터를 수집하거나 전송하거나 공유하지 않습니다.
검색어는 선택한 검색 엔진으로 바로 전달됩니다.

설정은 크롬의 sync 저장소에 보관되므로, 크롬 동기화를 켜 두었다면
본인의 구글 계정을 통해 기기 사이를 오갑니다. 이는 크롬의 동기화이지
TapTap 의 서버가 아닙니다 — TapTap 에는 서버가 없습니다.
